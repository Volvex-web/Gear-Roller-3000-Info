# Gear Roller 3000

Gear Roller 3000 is a free add-on for World of Warcraft: Forever.
It helps players compare equipment upgrades, manage group loot rolls,
and review loot results from their last dungeon run.

## Dungeon Loot

We plan to use [ForeverDB.net](https://foreverdb.net) as a data source
for dungeon bosses and their loot. The catalogue will be fetched when
preparing add-on releases and displayed offline in the Dungeon Loot panel,
with a visible link to ForeverDB.net. Observed Forever drops and Classic
reference data will be labeled separately where that information is available.
